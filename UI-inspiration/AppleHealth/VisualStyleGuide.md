# Apple Health Visual Style Guide

This document captures the visual design patterns and UI elements from Apple Health app to serve as inspiration for our Plank Challenge application.

---

## Screenshot 1: Summary Screen (IMG_5015.PNG)

### Overall Layout
- **Screen Type:** Main dashboard/summary view
- **Navigation:** Bottom tab bar with icon + label format
- **Content Structure:** Vertically scrolling card-based layout

### Header Section
- **Title:** Large, bold "Summary" text (SF Pro Display, ~34pt)
- **Position:** Top-left aligned
- **User Avatar:** Circular badge with initials (top-right), pink/magenta gradient background
- **Background:** Gradient from warm orange (top) to purple/blue (middle), transitioning to light gray content area

### Card Design
- **Shape:** Rounded rectangles with generous corner radius (~16-20px)
- **Background:** White/off-white with subtle shadow
- **Padding:** Generous internal padding (~16-20px)
- **Spacing:** Cards have consistent vertical spacing between them (~12-16px)

### Mental Wellbeing Card
- **Section Label:** Uppercase, small, gray text ("MENTAL WELLBEING")
- **Dismiss Button:** Small "X" icon in top-right corner
- **Icon:** Teal/cyan colored clipboard with brain icon
- **Title:** Bold, black text (~17pt)
- **Description:** Gray secondary text, multiple lines
- **CTA Button:** Outlined button with blue text, rounded corners ("Take Questionnaire")

### Health Checklist Card
- **Similar structure to above**
- **Icon:** Red/pink checkmark badge
- **CTA Button:** Same outlined blue button style ("Review")

### Pinned Section
- **Section Title:** Bold "Pinned" with "Edit" link in blue (right-aligned)
- **List Item:** Icon + label left-aligned, "Today" + chevron right-aligned
- **Icon Style:** Small, blue, filled icon (bed for Sleep Score)

### Bottom Tab Bar
- **Style:** Floating/pill-shaped segmented control for main tabs
- **Selected State:** Light background highlight with colored icon
- **Unselected State:** Gray icon
- **Additional Action:** Standalone circular search button (right side)

### Color Palette (Observed)
| Element | Color |
|---------|-------|
| Header Gradient Start | Warm Orange (#F5A962 approx) |
| Header Gradient End | Purple/Lavender (#B8A5D6 approx) |
| Primary Action/Links | System Blue (#007AFF) |
| Card Background | White (#FFFFFF) |
| Page Background | Light Gray (#F2F2F7) |
| Primary Text | Black (#000000) |
| Secondary Text | Gray (#8E8E93) |
| Accent - Teal | #5AC8FA (approx) |
| Accent - Pink/Red | #FF3B30 (approx) |

### Typography
- **Title:** SF Pro Display Bold, ~34pt
- **Section Labels:** SF Pro Text, uppercase, ~12pt, gray
- **Card Titles:** SF Pro Text Semibold, ~17pt
- **Body Text:** SF Pro Text Regular, ~15pt, gray
- **Button Text:** SF Pro Text Semibold, ~15pt, blue

### Key Design Principles
1. **Generous whitespace** - Cards breathe with ample padding
2. **Clear hierarchy** - Bold titles, muted descriptions
3. **Actionable elements** - Clear CTAs with outlined button style
4. **Dismissible cards** - X buttons for optional content
5. **Warm, welcoming gradient** - Creates emotional connection at header
